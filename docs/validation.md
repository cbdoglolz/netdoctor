- 不进行页面请求 25 秒后，后台观测时间继续推进。启动初期显示初始化提示，不回退演示。
- 真实快照包含用户手机 → iStoreOS 的逻辑网关边，以及用户确认 / 待核实的物理和虚拟连接；按 MAC 与 mDNS 恢复部分名称，其余保持未知。
