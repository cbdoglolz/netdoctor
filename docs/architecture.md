# 当前架构与接入边界

v0.3.0：procd → Go 独立后台采集 → SQLite / nlbwmon → 受 root 会话保护的 API → React。浏览器只读缓存快照，不承担定时采集。每个观察携带来源、时间与可用状态。

## 数据与调度

本机资源：ubus、/proc 与 br-lan 接口计数。邻居、ARP、mDNS / HostHints 提供发现和名称线索；ICMP 并发限制为 4，关键设备按设置调度，普通设备目标 60 秒，批次忙时允许延后。被动设备不做定时 ICMP，也从 ARP 主动目标中排除。ARP 仅在 br-lan 的 /24 或更小 IPv4 子网执行。

nlbwmon 是流量累计的唯一计量来源，Go 读取其 JSON，不独立重复抓包计量。SQLite 事务同时保存增量与累计基线；首次读数和计数回落只建立新基线，避免制造负数或重复累计。此处理会舍弃缺乏可信基线的区间，因此不能当作完整账单。按 MAC 保存用户标注；随机 MAC 或更换地址仍可能造成身份变化，不能保证跨随机标识追踪。

SQLite 使用 WAL、单连接、时间清理和已用页容量淘汰。主库上限设置为历史预算的 75%，为 WAL / nlbwmon 留余量。统计 config 目录的主库、WAL、SHM 和 accounting 文件，达到预算 90% 或可用磁盘不足 64 MiB 时暂停写入。SQLite 缓存预算不是整个 Go 进程的硬内存上限。nlbwmon 独立进程的数据库代数和记录数另有固定限制，当前未将其配置动态联动到设置。

## 连接与管理数据

逻辑网关边表示用户确认的转发选择；物理 / 虚拟 / 无线边表示配置中的连接证据。二者分层，不能互相推导。线色表示两端当前可达性，不表示无管理交换机的实际端口协商结果；流量粒子仅用于存在本轮增量的逻辑边。

ESXi 使用 govmomi vSphere API，通过正常 TLS 或明确提供的证书指纹校验，读取 VM、电源状态、vNIC MAC、连接状态与端口组。尚未将其扩展到物理上联 / vSwitch 自动图谱，尚未进行目标 ESXi 实机验收。爱快、小米管理接口尚未实现，凭据不足时不尝试其他设备的密码。

## API 与安全

- `/api/snapshot`：后台缓存快照；启动初期明确返回初始化状态。
- `/api/history?range=24h|7d`：分桶趋势及所选时段流量，缺失区间不填零。
- `/api/config`：GET 脱敏，POST 校验、原子写入并在后续采集生效。
- `/api/version`、`/api/update`：公开 GitHub Releases，安装前确认、资产校验与健康失败回退。

API 复用本机 ubus root 会话，写请求必须同源。管理凭据仅保存在软路由的受限配置文件，不回传密码，不进入 URL、日志和仓库。仅绑定 LAN，无默认 WAN 开放。HTTP LAN 入口尚未完成 HTTPS 集成。
