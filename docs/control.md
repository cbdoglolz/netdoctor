# 统一控制首版 · v0.4.0

本版将 .6 配为操作管理中心，.144 为受管采集节点。现有只读快照联动继续保留。新增控制任务独立授权，**不是公共资料同步、备用中心或故障接管的实现**；原有备注、图标共享显示规则不变。

## 页面和操作

从「设备控制」选择执行节点；设备详情提供「管理上网与诊断」入口，可预选设备路径所在节点。

- 临时暂停：1–1440 分钟，到期恢复，仅控制本节点实际收到的该 IP + MAC 向公网发出的 IPv4 请求。
- 每日暂停时段：北京时间，支持跨午夜；约 10 秒核对一次。可停用、重新启用；过期临时策略需新建。
- 策略恢复：停用记录保留在列表。多个重叠策略按任一有效即阻断；停用一条不撤销其他策略。已停用或已到期策略可删除，操作历史保留。
- 主动诊断：指定 IPv4 的 Ping 与最多 6 跳路由追踪；两节点同一目标分别执行，存在少量启动时间差，不自动认定故障归属。
- DNS：使用目标节点的系统解析器，不代表终端使用相同 DNS。
- 服务：仅 nlbwmon 和 avahi-daemon 的状态与重启；后者未安装时明确失败。无任意 shell、网络重启、路由或代理控制入口。

任务状态区分已接收、执行中、已执行、失败与重启中断。报告首行显示结论，展开查看证据。请求 ID 在最近 100 条任务内去重，重复 ID 不同内容拒绝；超过保存范围不承诺去重。网络超时显示结果未知，必须先查询记录。

## 授权和接口

设备 config/control-settings.json 为 0600 私密部署配置，结构为 enabled、managerID、token、peerTokens（节点 ID 到独立控制令牌）。新安装默认关闭；现有只读令牌不能调用控制接口。配对与权限变更仍由可信部署端完成，没有网页授予管理权接口。

- `/api/control`：现有 root 会话保护、写操作校验同源。只有 managerID 等于本机节点 ID 才能发起写任务。GET 允许查看本机状态；管理中心可查询受管节点。
- LAN 8099 HTTPS `/control`：POST，校验独立控制令牌和指定管理节点 ID；只接受固定操作名单，保留证书指纹校验、LAN 目标限制和禁止重定向。
- 控制令牌与 root 密码不返回网页、快照或操作记录；只读快照接口的权限不扩大。

## 执行位置与防火墙边界

首版实测 eth0 入站的 x86 iStoreOS。使用独立 `netdev hnd_control` 表、eth0 ingress priority -500，先于当前软件 flowtable 执行。不修改 firewall4 表、UCI 网络配置、代理、DNS、IPv6、路由或卸载设置。硬件卸载配置启用时拒绝新建阻断策略。

策略同时匹配源 IP、源 MAC、本机 eth0/br-lan 下一跳 MAC，且仅阻断公网目的地址，保留私网/CGNAT/本机访问。排除范围见 controlTableScript。新建策略必须有本机近期（2 分钟内）路径证据、有效且新鲜的采集快照；基础设施类型与本机禁止作为目标。远端证据不能直接充当本机控制证据。

阻断元素最长存活 45 秒，节点每约 10 秒刷新；临时策略元素寿命不超过剩余时长。停用时清除元素；进程正常结束删除专用表，崩溃时元素到期放行。采集过期、IP/MAC 不符时不继续阻断。故障默认恢复放行，**不是不可绕过的家长控制或全天持续封锁承诺**。繁忙、故障期间时段切换可能延迟。

匹配计数表示规则实际命中的请求包，不表示终端所有上网方式均已断开。IPv6、其他网关、硬件卸载或不经过本机的流量不在覆盖范围；同 IP/MAC 恶意伪造未防护。软件流量加速的实际入口行为以实机计数校验。计数在专用表重建或服务重启后重新累计。

## 持久化、恢复与容量

config/control-state.json 保存最多 64 条策略、100 条任务和有限输出。原子文件替换，替换前同步文件内容；保存失败不确认任务接收。策略由目标节点保存执行，管理中心断开不取消已启用时段；这不等于已同步到备用中心。

任务单队列执行，最多 8 项等待/运行；Ping/追踪有超时，输出限长。重启把未完成任务标为中断，不重放服务重启。持久策略在采集恢复且身份匹配后重新核对执行。

升级保留 control-state.json、control-settings.json、原有 config.json、peers.json 和 history.db。回退前应先停用启用中的策略；旧版不读取控制记录，内核临时阻断最长约 45 秒后失效。设备端 backup-v040 包含升级前停止采集服务后复制的历史库与已有配置；密钥不公开。

## 后续

公共设备资料自动同步与持久备用、管理任期和手动接管仍需单独实现。本版没有流量限速、自动网关切换、AP/交换机控制、永久身份合并或 IPv6 控制。
